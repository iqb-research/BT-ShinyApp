# BTShinyApp

## Overview

`BTShinyApp` displays the results of the "Bildungstrend" studies on an interactive map of Germany and forms the basis for
https://www.iqb.hu-berlin.de/de/schule/bt-ergebnisbrowser/.

## Installation

```R
# Install from GitHub via
remotes::install_github("iqb-research/BT-ShinyApp")
```
